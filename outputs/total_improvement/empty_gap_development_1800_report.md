# Диагностика empty-green gap-out, development, 1800 с

Exploratory development comparison on seeds 2101–2130, separate from previous experiments. Every controller shares the same Poisson arrival stream per scenario/seed. Tests 0/1/3-second empty-current-axis gap-out against Fixed 8, Vehicle-actuated, Queue-based original/legacy and locked Queue-based Improved. These seeds are not a final test set.

## Методика

Для каждой пары сценарий/seed стратегии используют общий хэшированный поток. Процент изменения среднего ожидания рассчитан относительно указанного в сводной таблице baseline (`fixed_35` или `fixed`); если baseline не запускался, показано N/A.
