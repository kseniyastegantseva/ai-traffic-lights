# Bootstrap sensitivity using directional count residuals observed on VisDrone images

Resample observed signed per-approach count residuals from the 16-image evaluation set; this is a small diagnostic bootstrap, not an independent validation set.

## Методика

Для каждого сценария все стратегии запускаются на одинаковом наборе random seed. Ключевым baseline считается стратегия `fixed`; улучшение считается как снижение среднего времени ожидания относительно неё.
