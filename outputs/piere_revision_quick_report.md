# Быстрая проверка пересмотренной модели

Небольшой smoke-сценарий для проверки физики и формата результатов; не предназначен для научных выводов.

## Методика

Для каждого сценария все стратегии запускаются на одинаковом наборе random seed. Ключевым baseline считается стратегия `fixed`; улучшение считается как снижение среднего времени ожидания относительно неё.

## Парные различия queue_based

Разность определена как ожидание `queue_based` минус ожидание сравниваемого алгоритма; отрицательное значение означает меньшее ожидание у queue_based. Интервалы — 95% нормальная аппроксимация для среднего парного различия. P-value получено двусторонним точным знаковым тестом; внутри сценария применена поправка Holm.
