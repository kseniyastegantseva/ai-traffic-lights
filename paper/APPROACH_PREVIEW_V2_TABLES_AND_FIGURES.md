# План таблиц и рисунков Approach Preview v2

Источники v2 перенесены из приложенного ZIP в проект; `outputs/` исключён из Git и должен передаваться отдельно. Пути ниже относительно корня `ai-traffic-lights/`. Готовность ниже относится к наличию исходных данных, а не к готовности к публикации.

Дополнительный пересчёт сохранён в `paper/approach_v2_audit/final_outcomes.csv`, `validation_outcomes.csv`, `followup_contrasts.csv` и `CONFIRMED_RESULTS.md`; воспроизводящие скрипты находятся в `scripts/audit_approach_v2_outcomes.py` и `scripts/analyze_approach_v2_followup.py`. Подготовлен exploratory-рисунок `paper/approach_v2_audit/fairness_tradeoff.svg`, источники и пределы — дополнительный аудит. Ошибки и неопределённость pilot указать отдельно в подписи; он не заменяет исходный final.

| Таблица | Источник | Статус и контроль |
|---|---|---|
| Сценарии и нагрузки | `docs/APPROACH_PREVIEW_V2_PROTOCOL.md`, YAML в `configs/` | Сверить фактические генераторы и единицы. |
| Физика и регламент | протокол, config, `src/traffic_light/simulation.py` | Сверить исполнение и границы. |
| Датчик | протокол, `src/traffic_light/sensor.py`, YAML | Показать пресеты как синтетические, не калибровку. |
| Arms и выбор | протокол, `development_selection.json`, development JSON.gz | Проверить воспроизводимость выбора и сетки. |
| Этапы/seed | манифесты, YAML, `FREEZE.json` | Хронология freeze независимо не удостоверена. |
| Все контрасты с CI и Holm | `final_m6_contrasts.csv`, исходные JSON.gz | Основная метрика: 66 строк независимо пересчитаны; вторичные исходы пересчитаны отдельной семьёй Holm, см. `final_outcomes.csv`. |
| 1800/3600 | `final_m6_3600_contrasts.csv` и исходные JSON.gz | 36 основных строк пересчитаны; 3600 с только шесть сценариев. |
| Fairness | `final_m6_arm_metrics.csv`, JSON.gz | Максимальный красный — среднее максимумов по seed; отдельно проверить p95, max и направления. |
| Throughput, остаток, ожидание | `final_m6_arm_metrics.csv`, JSON.gz | Нужен пересчёт, описание цензурирования и единиц. |
| Ошибки датчика | `validation_m6_contrasts.csv`, validation JSON.gz | Проверить все варианты и размер выборки; final этих sweep не выдавать за выполненный. |
| Вычисления | `runtime_profile.json` | Доступны агрегаты, не ряд индивидуальных измерений; новое распределение не рисовать по агрегатам. |

Рисунки после проверки: (1) схема перекрёстка и зоны наблюдения; (2) архитектура измерений и управления; (3) flowchart rollout; (4) площади A/B/C/D по сценариям; (5) лес парных эффектов с 95 % CI и указанием нескорректированных интервалов; (6) динамика очереди только после отдельного воспроизводимого запуска с включённым сохранением временного ряда — в основном final `store_queue_series: false`; (7) компромисс средней площади и максимального красного с явно заданной агрегацией; (8) чувствительность validation к датчику; (9) 1800/3600 с только для общих сценариев; (10) распределение времени решения только после сохранения индивидуальных измерений. Первые три — схемы модели, не экспериментальные измерения. Основной текст ограничить наиболее информативными рисунками, остальные отнести к дополнениям. Для остальных рисунков скрипты и подписи ещё предстоит подготовить; отсутствующие значения не интерполировать.
