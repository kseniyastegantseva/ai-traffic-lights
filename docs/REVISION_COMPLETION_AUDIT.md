## Проверки этого аудита

- Пересчитаны summary means из отдельных runs для 1800 и 3600 с; расхождение с JSON summary менее `4e-14`.
- Пересчитанные средние сравнили с сохранёнными CSV summary; максимальное расхождение меньше `4e-14`.
- Проверены количество runs, уникальность ключей `(scenario, seed, controller)`, идентичность arrival hashes в каждой парной группе, длина `queue_series`, неотрицательность очередей и conservation identity.
- Проверены актуальные Git remotes/branches и свежесть `origin`; рабочая ветка совпадает с `origin/revision/piere-review`, `main` не изменяется.

## Финальная проверка и публикация изменений

- Английский и русский DOCX собраны `scripts/build_piere_manuscript.py`; `scripts/export_piere_pdfs.ps1` успешно экспортировал их через Microsoft Word. Word и PDFium подтвердили ровно 6 страниц у каждой PDF. После рендеринга просмотрены все страницы; пропусков, обрезанного содержимого и пустых страниц не обнаружено.
- Проверки: `ruff check .` — без замечаний; `pytest -q` — 60 passed. Использовано отдельное временное Linux-окружение Python 3.12, проект установлен editable без повторной установки уже доступных зависимостей. `git diff --check` прошёл.
- Временные превью удалены из рабочей копии. Docker daemon недоступен; LibreOffice отсутствует, PDF собраны установленным Microsoft Word.
- Изменения статьи, перевода, памятки авторов, ответа рецензенту и генератора DOCX включены в коммит этой задачи для `revision/piere-review`. Ветка `main`, опубликованное приложение и `outputs/` не менялись.
- Внешняя проверка авторами всё ещё нужна для соответствия точному шаблону конференции и сверки ответа с оригинальным письмом рецензента; письмо в доступных материалах отсутствует. Ограничения provenance detector и отсутствия независимого holdout указаны в рукописи.
